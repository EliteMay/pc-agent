# PC Agent v0.12 cloud-only safety plan

Status: design and test plan; not approved for deployment.
Source of truth: GitHub main. This branch changes documentation only.

## Scope
- copy_file: bounded regular-file copy, no overwrite.
- move_path: same-volume file/directory move and rename, no overwrite.
- Keep existing allowed-root, sensitive-path, approval, journaling and Game Safety boundaries.
- No Windows PC, Desktop Commander, local updater, game or production Gateway changes.

## Critical safety gaps to close before merge
1. Approval snapshot: approvalSummary and execute currently call plan independently. Bind approval to immutable operation ID, canonical source/destination, source type, file identity, size and SHA-256 for file copy, with expiry; fail closed on mismatch. Do not silently regenerate approved identity.
2. Source substitution: move_path checks canonical path but not identity/content between approval and execution. Use appropriate identity and change checks; directories require conservative handling for tree changes.
3. Destination race: existsSync followed by renameSync is not atomic no-clobber. Define and implement a Windows-safe no-replace move strategy or explicitly refuse unsupported cases. Never depend on a preflight exists check alone.
4. TOCTOU: source/destination path and parent can change after validation; use handles or OS primitives where possible and document residual races.
5. Verification/rollback: copy cleanup must not delete an unrelated file that replaced the output; move post-rename verification failure must be recorded as uncertain outcome rather than blindly retried.
6. Scope: deny allowed-root movement, symlinks/junctions/reparse points, sensitive paths, self-descendant directory moves and cross-volume moves. Fail closed on ambiguous Windows path semantics.

## Required tests (mocked/unit + Windows CI)
- happy paths: file copy, file move, directory move, rename.
- invalid inputs, nonregular sources, oversized copy, existing destination, missing parent.
- sensitive/escaped paths, link and junction paths, case-insensitive collisions, allowed root and descendant checks.
- mutate source after approval (same bytes length, different bytes); replace file at same path; directory tree change.
- create destination between approval and execution; destination-parent swap; source swap.
- copy interrupted mid-operation; verification failure and ownership-aware cleanup; move verification failure and UNKNOWN_OUTCOME.
- duplicate operation_id, expired request, missing approval, denied capability, Emergency Stop and game pause.
- no unexpected shell execution, no outside-root effects; Gateway contracts preserve Agent final authority.

## CI and release gates
- Run unit and integration tests on Windows CI; include race-focused tests with deterministic synchronization where feasible.
- Gateway/schema changes only after review and contract tests; no production migration/deployment without explicit release gate.
- Draft PR only until all safety tests pass and Windows real-device verification is performed.
- Record exact tested commit SHA and known residual risks; do not claim complete based on mocked tests alone.
